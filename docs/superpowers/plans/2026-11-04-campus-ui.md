## Global Constraints

- app.js, api.js, data.js and icons.js remain byte-identical to baseline.
- Existing IDs, inline handlers, API and permissions remain unchanged.
- Base colors: #F5F7F6, #FFFFFF, #23332D, #65746C, #34785B, #DDE5E0.
- Use local fonts, restrained motion, keyboard focus and mobile adaptation.
- No deployment or push to school servers without a usable authorized server session.

## Review Focus

- CSS cascade must override the legacy cyberpunk login and inline cover styles.
- Teacher tables remain usable at small widths.
- Notification and account overlays remain visible above the new navigation.
- Hidden app/login states remain controlled by existing JS.
- Existing course tabs, form fields and buttons remain usable.
