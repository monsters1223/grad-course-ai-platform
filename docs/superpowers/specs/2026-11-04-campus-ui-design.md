# 研究生通识课平台界面美化方案

依据：用户要求学生端、教师端一并美化，功能保持原样；补充偏好为简洁、弱化 AI 视觉、少用靛蓝。前端基线 `3b090e918332174dc8b4f8a8ec98adc75da8e798`，后端基线 `3fb782cfbfda17675fc9bbe52ddf75b4fd236ae3`。

## 改动范围

调整登录、共用侧栏和顶栏、学生课程列表与学习页、测验作业、讨论群聊、小组签到、学情、教师课程列表和六个管理标签页、通知和弹窗的视觉样式。保留全部文案含义、数据、入口、表单字段、DOM 标识、事件绑定、API、权限、路由和 AI 接入逻辑。用户现有页面与接口是设计约束。

## 方案取舍

1. 在现有组件之上增加统一样式层：最小改动即可统一师生两端，业务脚本能逐字节保持一致。采用此方案。
2. 重写页面布局和组件：自由度更高，但会触及大量动态模板和事件绑定，不适合本次只做美化的边界。

这是基于用户功能约束作出的实现选择，不额外引入框架、构建系统、在线字体或图标依赖。新样式文件由前后端两份入口同时引用；后端仓库的 `static/` 与独立前端仓库保持一致。

## 视觉规则

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 页面浅灰 | `#F5F7F6` | 内容背景 |
| 白色 | `#FFFFFF` | 导航、表单、内容面板 |
| 深灰绿 | `#23332D` | 正文、标题 |
| 次要灰 | `#65746C` | 说明和次要信息 |
| 松绿色 | `#34785B` | 主按钮、链接、选中状态 |
| 浅灰边线 | `#DDE5E0` | 表格、分隔线、输入框 |

错误、警告和成功状态保留语义区分，颜色之外仍显示文字。AI 模块使用相同组件规则，不使用独立霓虹紫色或发光样式。

字体采用本机“微软雅黑 / 苹方 / Segoe UI”，保持校内网络下可用。页面标题约 26px、分组标题 18px、正文 14px、辅助文字 12–13px；正文左对齐。登录页用排版与留白建立层级，取消网格扫描、霓虹背景和持续动画。

桌面端保留约 224px 左侧导航和顶部搜索；主要内容宽度按课程、学习和管理场景调整，避免内容全部塞入相同的卡片。课程封面保留现有内容，统一尺寸、圆角与标题层级。教师表格突出列名、行间距和操作按钮。

```text
桌面
┌──────────┬──────────────────────────────┐
│ 平台名称 │ 搜索                    通知 账号 │
│ 角色     ├──────────────────────────────┤
│ 现有导航 │ 页面标题 / 课程名称             │
│          │ 现有筛选或标签                  │
│          │ 课程 / 学习内容 / 管理表格        │
└──────────┴──────────────────────────────┘
窄屏
┌────────────────────┐
│ 平台名称 / 现有导航   │
├────────────────────┤
│ 搜索 / 通知 / 账号    │
│ 标题与现有页面内容    │
└────────────────────┘
```

圆角按用途区分：输入框和按钮约 6–8px，内容面板约 10–12px，头像保留圆形。平面内容靠间距和边线区分，阴影只用于浮层。保留明确键盘焦点；适配小屏；尊重减少动态效果设置。

## 自我审查

最初考虑的深蓝侧栏与青绿 AI 强调仍有常见 AI 平台视觉特征，已按用户偏好改为白色侧栏、灰绿文字和统一绿色操作色。没有增加展示性大数字、宣传横幅、装饰标签或新功能。辨识度来自安静的课程工作区和清晰的师生操作层级。

## 验证与交付

保留并比较 `app.js`、`api.js`、`data.js`、`icons.js` 的文件哈希；核对入口全部原有 ID 和事件绑定；检查两仓库资源一致性。用本地隔离的模拟接口检查学生与教师的代表页面、窄屏和弹窗；模拟数据只用于 QA，不写进产品。连接不到校内地址时不宣称完成线上验收。

交付包含两仓库可应用的变更、静态资源包、预览图及部署说明。当前没有校内服务器会话与部署目录，交付本地可审查结果，不将本地修改表述为已经上线。
